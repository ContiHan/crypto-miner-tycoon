## Adding a doc

1. Drop the `.md` in `docs/`.
2. Add a row under the matching heading above (or a new heading if it's a new
   category — e.g. `🧪 Testing`, `🚀 Ops/Release`).
3. Keep each doc focused on one topic; link between them with relative links.
